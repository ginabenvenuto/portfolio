# Gina Benvenuto — Portfolio

Personal portfolio showcasing products built with Claude Code.

**Live:** [gina-portfolio.vercel.app](https://gina-portfolio.vercel.app)

## Projects featured
- [Job Opportunity Checker](https://github.com/ginabenvenuto/job-scam-checker) — AI tool for evaluating job legitimacy
- [SF Parents Hub](https://github.com/ginabenvenuto/sf-parents-hub) — Community directory for SF parents & caregivers

## Built with
- [Next.js 14](https://nextjs.org/) (App Router)
- TypeScript
- Tailwind CSS
- Deployed on [Vercel](https://vercel.com)
- Built using [Claude Code](https://claude.ai/code)

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
