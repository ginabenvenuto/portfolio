# Gina Benvenuto — Portfolio

Personal portfolio site. Static HTML, built with Claude Code.

**Live:** [gina-portfolio.vercel.app](https://gina-portfolio.vercel.app)

## Projects featured
- **Discern** — AI tool for evaluating job legitimacy
- **Village** (coming soon) — Community resource for SF parents & caregivers

## Stack
- Single `index.html` — no build step
- Instrument Serif + Jost (Google Fonts)
- Deployed on [Vercel](https://vercel.com)
- Built using [Claude Code](https://claude.ai/code)

## Run locally

Just open `index.html` in your browser, or serve the directory with any static server.
